## 项目简介
本项目隶属于 B站「第一名柠檬」创作的**宇宙（YZ）虚构世界观**，以 Minecraft 为载体还原 新州 这座表现体城市。仓库承载项目官方导航站源码、世界观设定文档、轨道交通设计素材，整合包与资源文件通过 Releases 分发。

## 世界观背景
宇宙（YZ）是一套幻想超现实世界观，同时以最高级公司的形式存在于设定中。世界观内的行动主体为各类公司，城市存在于人的脑海之中，并可通过 Minecraft 等形式制作成 表现体 用于展示。

世界观核心规则：
- 所有组织、城市、事件均为虚构，与现实无关联
- 公司是世界观内的唯一行动者，城市与公司为平级关系
- 表现体仅作展示，无需完全复刻脑海中的完整城市

## 新州城市概览
新州是世界观中继天戈、天山之后的第三座表现体城市，基于 Minecraft 1.19.4 建造，地图种子为 “99”。

- **轨道交通**：包含 3 条地铁线路、1 条轻轨、4 条高铁线路、航空线路及缆车线路，覆盖城市内外通勤
- **核心区域**：新州站（最大地铁站）、红星北站（设施最完善站点）、沙恶商业街（核心商业区）
- **周边联动**：与金宝、机航主线等城市互联互通，支持跨城高铁与航空通行
